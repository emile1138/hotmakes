# HotMakes website

Public static website for HotMakes, built for GitHub Pages. HTML and CSS only, with no dependencies, database, tracking, or build step.

## Preview
Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## Publish
In repository Settings → Pages, select Deploy from a branch, `main`, `/ (root)`, then Save. The initial address is https://emile1138.github.io/hotmakes/.

Do not configure the custom domain until the site is reviewed. The intended domain is hotmakes.com. Domain setup is separate; no CNAME is included yet.

## Content
- `index.html`: public copy and links
- `styles.css`: responsive design
- `assets/`: supplied brand assets

Only public website content belongs here. Keep credentials, planning documents, personal information, and private agreements elsewhere.

The YouTube channel and social links were sourced from Caleb's public HotMakes portfolio page. Confirm these destinations before launch. Episode embeds, schedule, current hosts, and additional community/contact links can be added once confirmed.
